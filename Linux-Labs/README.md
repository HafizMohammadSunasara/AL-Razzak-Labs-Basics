# 🐧 Linux Labs

Hands-on Linux laboratory work completed as part of **AL RAZZAK LABS**.

This repository documents practical Linux administration, system management, networking, security, and command-line exercises completed through 60 hands-on labs.

## 📊 Progress

**60 / 60 Labs Completed**

> Practical Linux learning through hands-on experimentation and command-line exercises.

## 🎯 What This Repository Covers

The labs cover:

- Linux filesystem management
- File and directory operations
- File permissions and ownership
- Users and groups
- Shells and shell scripting
- Processes and job management
- Environment and shell variables
- Networking and file transfers
- Package management
- System administration
- SSH, SCP and SFTP
- Text processing with grep, sed and awk
- Disk management and storage
- Cron and task scheduling
- System logs and monitoring
- Firewall configuration
- Linux services
- Bash configuration
- SELinux fundamentals
